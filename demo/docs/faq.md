# よくある質問

## 非公開のS3に置いたmdファイルを表示できますか

できます。サーバー側で署名付きURLを発行して `src` に渡します。期限が切れて取得に失敗した場合は、ページ一覧を取得し直して1回だけ取得し直します。バケットにはCORS設定が必要です。

## 同じ画面に2つ置けますか

置けます。どちらかに `url-param="false"` を指定し、URLの書き換えを止めてください。

## 狭い画面ではどう表示されますか

表示幅が768px未満になると、サイドバーはボタンで開く形になり、目次は本文の上に折りたたまれます。
