# オプション

## オプション一覧

| オプション | タグの属性 | 内容 |
| --- | --- | --- |
| pages | pages | ページの配列、またはそれを返すURL |
| currentId | current-id | 表示するページのID |
| baseUrl | base-url | `md` のページの相対パスの基準 |
| imageResolver | （プロパティのみ） | 画像パスを表示用URLに変える関数 |
| fetch | （プロパティのみ） | 一覧と本文の取得に使う関数 |
| urlParam | url-param | URLに反映するクエリ名。`false` で反映しない |

## URLへの反映

ページを切り替えると、URLのクエリ `page` が切り替え先のIDになります。ブラウザの戻る・進む、リンクの共有がそのまま使えます。

組み込み先が `page` を使っている場合は、`urlParam` で名前を変えます。
